# Revisión de hechos de las páginas locales (9-nov-2026)

Seis revisores (Claude Sonnet 5.5, en paralelo) comprobaron con fuentes cada afirmación sobre el mundo real de las
73 páginas locales (`src/textos`) y de los datos de la portada (`src/datos/zonas.ts` y `src/datos/provincias.ts`).
Lo que no tenía una fuente fiable se corrigió o se quitó. No se revisó lo que la consultoría dice de sí misma
(servicios, forma de trabajar y datos), que confirmó Juan Luis, ni las distancias desde Alicante, que ya estaban
aprobadas.
